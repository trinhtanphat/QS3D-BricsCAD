# Full source review — 2026-08-10

This review continues the clean-room BricsCAD V25 implementation while preserving the native BricsCAD viewport and the BLT3D-familiar side-panel workflow described in `docs/UI-SPEC.md`.

## What was reviewed

- Core domain, persistence, formulas, quantity/rebar/reporting and model-health paths.
- BricsCAD V25 adapter, document lifecycle, semantic capture, native 3D generation, Xref/layer integration and viewport commands.
- Main workspace, right-side drawing/layer palette, BQ, Model Health, Recognition and Revision UI.
- Installer/runtime helpers, preflight policy and manual-only GitHub workflows.
- Concurrent commits already present on `main` were preserved and treated as the new base instead of being overwritten.

## Fixes in this batch

### BLT-style UI / UX

- Main workspace wording is consistently Vietnamese instead of mixed `Add/Delete/Pick/Locate/Top/Model Health` labels.
- Removed placeholder Unicode refresh glyphs from the principal docked palettes.
- Reduced workspace minimum widths to preserve more of the native BricsCAD viewport while retaining the three-panel BLT-style layout.
- Added tooltips/status text where an action can otherwise be ambiguous.
- Drawing/Xref list now uses `Loại = MODEL/XREF` instead of the misleading `Tỉ lệ` column.
- `Gỡ Xref` explicitly communicates that the external source file is not deleted.
- Selecting an Xref row synchronizes the corresponding direct instances into the current CAD selection; `Bỏ chọn` clears both the row and implied CAD selection.
- Recognition and Revision grids now use Vietnamese review/quantity labels.
- Shared theme now covers Window, DataGrid, DataGridRow/Cell/Header, ComboBox popup items, ToolTip and read-only fields so secondary dialogs keep the same dark CAD visual language.

### Family/property editing

- Preserved the newer `Func<string,string>` property-editor normalization path and `ProjectFamily` change notification introduced by the concurrent hardening batch.
- Blank/duplicate family names stay rejected.
- Dimensional family properties reject invalid, NaN and Infinity values, accept current-culture numeric entry where possible, then normalize persisted numeric text to invariant format.
- Property propagation still dirties existing family elements so downstream quantities can regenerate.

### Xref behavior

- Preserved the new direct `XrefService` API implementation (`ReloadXrefs` / `DetachXref`) instead of command-string emulation.
- Row selection and Move now target the selected Xref in the active space.
- Reload/detach remain name-targeted and wrapped in the existing status/error UX.

### Native 3D correctness and transaction safety

- Preserved the new INSUNITS-aware conversion path for inch, foot, millimeter, centimeter, meter and yard drawings.
- Wall/structural dimensions reject non-finite values.
- Generated geometry replacement is now two-phase: the DWG transaction must commit successfully before semantic `GeneratedSolidHandle` metadata changes.
- A failure after an old generated solid is tentatively erased therefore rolls the DWG back without leaving the in-memory project pointing at a non-existent new handle.
- Cleanup resolves and erases only a tracked `Solid3d`; a stale handle that resolves to another entity type is not erased.
- Structural builders construct/validate the replacement solid before erasing the previous generated solid, so an unsupported source shape does not destroy valid generated geometry.
- Generated solids remain separate from semantic source handles, preventing generated output from being reinterpreted as source geometry.

### HT_Phòng safety

- The `Bỏ HT` action now uses `QS3DUNTRACKFINISH` and only removes FloorFinish, Waterproofing, Skirting, WallFinish and CeilingFinish semantic records.
- Generic `QS3DUNTRACK` remains available for deliberate general-purpose untracking.
- Neither command erases CAD geometry.

### Quantity/BQ correctness

- `Tính lại` now performs a real regenerate and rebuilds the BQ rows instead of only reapplying the current UI filter.
- Existing floor/category filters are preserved when possible after recalculation.
- Snapshot-only BQ fallback now maps the live document INSUNITS to `DrawingUnit` instead of hard-coding millimeters.
- Unsupported/undefined INSUNITS explicitly falls back to millimeters with a status warning rather than silently pretending the unit was known.
- Locate now reports when a fallback/non-semantic row has no semantic handles rather than presenting a no-op as success.

### Security / resilience preserved from concurrent main

This review intentionally keeps the stronger hardening already merged before this commit:

- QSDB parser prohibits DTD processing, disables external XML resolution, limits XML characters and rejects oversized project files.
- Persistence recovery and regression tests cover malicious/invalid XML and load fallback behavior.
- BricsCAD V25 installer helper computes SHA-256 and normally requires a valid Authenticode signature from a recognized Bricsys signer, with an explicit controlled override for certificate-chain/offline exceptions.
- Formula/resource guards, quantity/health validation and the newer family-edit synchronization remain intact.

### Regression guard

`scripts/preflight.py` now checks the current architecture rather than older placeholder assumptions. It protects:

- manual-only CI policy;
- no committed proprietary BricsCAD assemblies/private DWG reference artifacts;
- net48/external BricsCAD references;
- QSDB DTD/size hardening;
- complete CAD-unit mapping;
- two-phase generated-geometry replacement and finite dimensions;
- Xref selection/reload/detach behavior;
- family numeric validation and finish-only untracking;
- dark DataGrid theme coverage;
- real BQ recalculation plus unit-aware fallback;
- installer signature/hash verification.

## Real BricsCAD V25 runtime gate still required

Source review is not a substitute for a licensed V25 runtime. Before treating a release as runtime-verified, use a Windows machine with BricsCAD V25 and run the repository's manual gate:

1. Build Release x64/net48 against the installed V25 managed assemblies and `NETLOAD` the plugin.
2. Open `QS3D`; inspect the docked layout at Windows scaling 100%, 125%, 150% and 200% for clipping, splitter behavior and retained viewport space.
3. Attach an Xref, select it in the right panel, verify CAD selection sync, Move, Reload and `Gỡ Xref` behavior.
4. Create/capture a wall LINE in at least mm and one non-mm drawing; build 3D and verify position, width, height and offset.
5. Rebuild the same wall/structural source and confirm exactly one current generated solid remains.
6. Force a deliberately invalid source/dimension case and verify the previous generated solid/project metadata stay consistent.
7. Edit family dimensions, open BQ and click `Tính lại`; verify regenerated quantities change without reopening the window.
8. Verify Recognition, Revision, BQ and Model Health dark selection/header states.
9. Re-run malicious/invalid `.qsdb` recovery cases and the signed/hash-pinned installer helper as appropriate.

GitHub Actions remain manual-only. This source review/commit is not authorization to dispatch them.
